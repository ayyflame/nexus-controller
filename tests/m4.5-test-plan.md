## Before you start (5 minutes)

1. Install the build, start NEXUS and plug in the DualSense with a USB data cable.
2. Controller › Virtual Output:
   - **Use the experimental virtual controller** is on;
   - **Xbox 360** is selected;
   - "Virtual controller now" shows **Xbox 360 connected**.
3. Keep `joy.cpl` handy: press Win + R, type `joy.cpl`, press Enter. Select **Controller (XBOX 360 For Windows)** → **Properties** to watch the buttons NEXUS sends.
4. Create a test macro in Macro Studio:
   - Name it **Test A**: Cross, press time 50 ms, wait after 50 ms;
   - trigger **R3**, mode **Repeat While Held**;
   - make sure it is on in the current profile.

In `joy.cpl`, Cross is **button 1** and R3 is **button 10**.
